# trading-system-notes 精读

> 配套 [`../trading-system-notes/`](../trading-system-notes/)(来源 `zzxscodes/trading-system-notes`;不在仓库里,用 [`tools/bootstrap_source.py`](tools/bootstrap_source.py) 重建)的**强化学习笔记**。
> 方向:C++ Infra / HFT 求职与自学。

## 这是什么

原仓库的笔记是**速查/备忘**风格——命令、代码片段、表格、要点罗列,默认读者已经懂概念。
本目录是在其之上补齐的一层:

- **原理**:为什么这么做,底层机制,硬件/内核层面发生了什么
- **心智模型 + 图**
- **读代码**:逐段讲原仓库给的代码,能看懂、能讲、能挑坑
- **面试考点**:这个知识点在 C++ Infra / HFT 面试里怎么被问,标准答法,陷阱题

## 组织方式

- 目录结构镜像原仓库的 7 章
- 每个源主题一个 `.md`,内部按"轮次"(子主题)累积
- [`进度追踪.md`](进度追踪.md) 是总进度表:全部 94 节 + 占位专题,优先级、状态、强化笔记链接

- 笔记里 `:line` 锚点指向的源笔记不在仓库里:`python tools/bootstrap_source.py` 会在**本仓库目录的同级**创建 `trading-system-notes/`(固定上游 `9a8f2f6`,再用 `tools/_split_notes.py` 拆分)。布局:

  ```text
  <某个目录>/
  ├── trading-system-notes-study/    ← 本仓库
  └── trading-system-notes/          ← bootstrap 生成,不进 git
  ```

## 学习形式(已约定)

| 项 | 约定 |
|---|---|
| 教学形式 | 🔴 核心必学:讲透(原理→底层机制→代码→面试考点)+ 讲完 2-3 题检验。🟡/⚪ 低优先级:视是否值得掌握,直接讲一遍建立直观,**不出检验题** |
| 节奏 | 🔴 一个子主题一轮,讲完确认再继续;🟡/⚪ 轻讲不设检验关卡,可连续过 |
| 产出 | 每主题一份强化笔记(轻讲版不含检验题)+ 维护进度追踪表 |
| 手写代码 | 不要求手写;目标是**看懂 / 能讲 / 能挑坑 / 懂权衡** |
| 顺序 | 章内默认按进度表编号顺序走(不因优先级重排),用户另有指示除外 |
